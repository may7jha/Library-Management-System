Project Title: Library Management System (Web Application)
## Live App:
https://library-management-system-jfuu2jjtzjv2b2gfmcny6c.streamlit.app/

Tech Stack: Python, Streamlit

Description:
A simple library management application that allows the user to:
- Add books to the library
- View all available books
- Store and manage library data using a JSON file

This project uses basic Python concepts along with Streamlit to build an interactive web-based interface.
